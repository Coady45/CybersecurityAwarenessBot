# Cybersecurity Awareness Bot

## Overview

Cybersecurity Awareness Bot is a C# console application designed to educate users about staying safe online. The chatbot provides information about cybersecurity topics such as password security, phishing attacks, online privacy, and safe browsing practices.

## Features

- Voice greeting when the application starts
- ASCII cybersecurity logo display
- User name personalization
- Interactive chatbot conversation
- Cybersecurity awareness responses

## Technologies Used

- C#
- .NET 8
- Visual Studio 2022
- GitHub
